# Asg3

Level Design - Vertical layout 

Total 5 rooms (Different Scenes!)

[SAM] 1st room - Simon Says / Memory Game with Target Practice (state patterns) 
Each wrong press will reset the code,(play with code then just physical requirement )/state pattern 

[QIN] 2nd room - Pressure Plates (rule based, strategy pattern)
Maybe can have objects of different weights in the room and the player has to find the right combination of items that are heavy enough
Sequence-based hints (e.g. the 5kg object cannot be next to the 3kg object)

[QT] 3rd room - Circuit route room (vectors, physics) and play movement controls 
2–3 wires, each going from a coloured source to the matching socket across the room.
Each wire has a length limit, so the player has to plan a short route.
Wires can’t cross each other.

[ANGELA] 4th room - Mirror lighting (RayCasting)
Press buttons to flip or rotate objects/Mirrors to reflect light at the correct direction to unlock the next room.

[DAYA] 5th room - Room with weeping angels (seen check, raycasting and viewports)
3 weeping angels guarding a table near the gate. Collect all the skulls and place it on the table near the gate to unlock the level.
